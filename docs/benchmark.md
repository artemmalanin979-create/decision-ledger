# Измерения на предварительном демо

## Условия

Один вымышленный телеком-кейс с двумя срезами испытаний. Оба подхода использовали gpt-6.1-sol (medium) через Codex CLI 0.166.0. Агент получил документы и CSV последовательно в трёх новых сеансах. В первом уточнил задачу, во втором сохранил стратегию, в третьем продолжил после решения и новой выгрузки. История чата не переносилась. Для обычного чата те же исходные материалы и уточнение передавались одним текстом, а при сверке добавлялись предыдущий ответ и новая выгрузка. Команды и файлы проекта в этом режиме не использовались.

Время — wall clock одного запуска CLI, включая работу инструментов и ожидание модели. Сессии двух подходов могли идти параллельно. Токены — счётчики завершённых ответов CLI, включая повторно переданный контекст. Попадания в кэш входят во вход. Запись не включает ожидание человека. Модель работает по подписке, точное списание недоступно. Сторонних платных инструментов для исследования не было. Таблицу из журнала можно сверить с [JSON](demo/measurements.json).

## Что изменилось

- Оба подхода предложили подготовить настроенный резерв для прямого подключения и отложить старый шлюз до дополнительных данных. После сверки оба верно оценили старый шлюз. сеть 20/20, подтверждённая покупка 14/20, ложный успех 6/20. Общий результат скрывал провал обоих порогов в этой группе.
- Обычный чат написал достаточный содержательный отчёт и был быстрее в этом замере. Для продолжения предыдущий ответ и данные подали повторно. Агент зафиксировал пять источников, версионность, явное утверждение, зависимости и обязательства. Новый сеанс восстановил историю из каталога, показал область перепроверки и подготовил отдельное решение о допуске. Старый снимок совпал с первоначальным файлом побайтно.
- Контрольные примеры в исходном сценарии допускают подготовку двух схем до сверки. Фактический прогон выбрал более узкую подготовку из-за всего четырёх конфигураций старого шлюза и неизвестной стоимости устранения расхождений. Новые данные перевели рекомендацию от подготовки к допуску учебного пилота для прямой схемы и дали измеримое основание для исключения старого шлюза.
- Короткая независимая проверка на фильтре звонков воспроизвела другой знаменатель, корректные доли и контрольную точку. Это проверка переноса, без нового полного цикла стратегии.

## Действия оператора и ошибки

Оператор передал первоначальный запрос, уточнение руководителя и финальный CSV, сыграл роль комитета для двух команд подтверждения. В веб-части команда заранее проверила три первичные страницы и подготовила краткие снимки. В замер обычного чата входят ответы с теми же снимками. Труд подготовки данных, репозитория и видеомонтажа не включён в стоимость решения.

Попытка начать с gpt-5.4-mini отклонена аккаунтом до результата и исключена из таблицы. В замере использована модель из локального каталога. Агент обновил первоначальный черновик после уточнения клиентского обещания, повтор отражён в счётчиках. Замер использовал версию агента из поля agent_commit в JSON. Дополнительные проверки границ SQLite, отзыва источника и подтверждений внесены после начала основного замера. Итоговый CLI проверен отдельно.
