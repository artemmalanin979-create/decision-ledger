# Ответ руководителя продуктовой команды

На ближайшем комитете нужно выбрать следующий шаг на месяц. Сравните четыре варианта.

1. Оставить текущую обработку звонков и сохранить команду для следующего ограниченного теста.
2. Расширить режим предупреждения с добровольным подключением.
3. Расширить жёсткую блокировку высокого риска с добровольным подключением.
4. Закрыть инициативу и высвободить команду для другой задачи.

Команда может подготовить только один следующий запуск. Для расширения нужен прирост доли непринятых спам-звонков на 3 процентных пункта или больше относительно текущего режима. Порог пропущенных важных звонков — 0,30% от всех вызовов пилота в целом и отдельно в каждом профиле. Выше порога расширять режим нельзя. Среди режимов, проходящих оба критерия, приоритет у того, который даёт больший прирост по спаму.

До закрытия окна сверки можно выбрать рабочий вариант и подготовить ограниченный следующий этап. Начать его можно после проверки итогового среза по всем профилям. Рекомендация нужна для голосовых вызовов участников следующего этапа. Решение по запуску на всю сеть потребует отдельной проверки.
